# DormMart logo

The supplied logo is saved unchanged as `dist/assets/dormmart-logo.png`.

Header, sign-in and footer use its emblem and wordmark through CSS viewports in `dist/brand.css`. No artwork is redrawn or recoloured. An ivory background keeps the original blue/orange readable in both themes. Each home link has an accessible DormMart label; decorative image pieces have empty alt text.

The SVG browser icon embeds the original artwork and frames the emblem. The original image is also referenced as the Apple touch icon. These assets are bundled locally and require no image CDN.

Brand integration also restores readable text in the homepage search input in dark mode and preserves safe-area spacing for mobile navigation.
